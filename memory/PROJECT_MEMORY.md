# PROJECT MEMORY

WABOGADOS es un ERP jurídico.
Núcleo: Dashboard, Clientes, Expedientes, Abogados, Actuaciones, Agenda, Documentos, Evidencias, Mensajería, Seguridad y Auditoría.
Las evidencias originales son inmutables y se generan derivados optimizados.

La web pública incorpora una portada renovada, páginas por área jurídica e iconos
acordes al servicio. La analítica está en un panel privado de administración, sin
contador público, cookies ni fingerprint; los visitantes son estimaciones de
navegación, no personas identificadas. Estado comprobado y límites operativos en
`CURRENT_STATE.md` y `session_summary.md`; no guardar secretos en esta memoria.
