# Memoria Persistente

Esta carpeta contiene conocimiento persistente del proyecto.
No utilizarla como log exhaustivo.

## Orden de lectura para retomar

1. `../AGENTS.md`: instrucciones del proyecto.
2. `project_context.md`: arquitectura y contexto.
3. `CURRENT_STATE.md`: estado vigente consolidado y advertencias de despliegue.
4. `session_summary.md`: entregas, archivos, pruebas y relevo de la última sesión.
5. `NEXT_STEPS.md`: prioridades actuales; `KNOWN_ISSUES.md` si aparece un problema.
6. `learnings.md` y `DECISIONS.md`: conocimiento reutilizable y decisiones (ADR-064).

`IMPLEMENTED_FEATURES.md` describe las funcionalidades entregadas.
Los bloques históricos con cifras/planes anteriores no prevalecen sobre el
estado vigente. No almacenar credenciales, tokens ni copias de conversaciones.
